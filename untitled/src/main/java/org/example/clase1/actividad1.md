# Actividad 1
## Comparación de los lenguajes

| Lenguaje    | Usos Principales                           | Ventajas                                      | Desventajas                                   | Ejemplo                           |
|------------|------------------------------------------|----------------------------------------------|----------------------------------------------|----------------------------------|
| **Java**   | Aplicaciones empresariales, móviles (Android). | Portabilidad (JVM), comunidad amplia.       | Verbosidad, menor rendimiento que C.        | `System.out.println("Hello");`   |
| **C**      | Sistemas operativos, software embebido.  | Alto rendimiento, control sobre hardware.   | Manejo manual de memoria, sin OOP.          | `printf("Hello, World!");`       |
| **JavaScript** | Desarrollo web (front y back-end).   | Compatible con navegadores, rico ecosistema. | Tipado dinámico puede generar errores.      | `console.log("Hello!");`         |
| **Python** | Ciencia de datos, inteligencia artificial. | Sintaxis simple, versatilidad.               | Más lento que C y Java en tareas intensivas. | `print("Hello, World!")`         |

**Fuente:** Documentación oficial de cada lenguaje y artículos técnicos de GeeksForGeeks y W3Schools.
